CHORD LAB STUDIO 1.6 · INSTALLING ON A MAC

1. Open Terminal (Spotlight: "Terminal").
2. Type  bash  and a space. Drag the file
   «Εγκατάσταση Chord Lab Studio.command» (Install Chord Lab Studio)
   from this folder into the Terminal window. Press Return.
3. When it asks about old versions: ν = move them to the Trash, ο = keep them.

The app goes into Applications, or into the folder where an earlier
Chord Lab Studio is already installed, and opens by itself. To choose
another folder, add its path after the file name in step 2.
Your projects stay; version 1.6 opens the last project of version 1.5.

Why Terminal: the file has no Apple Developer signature, so a double-click
may be blocked. Terminal runs it without that obstacle. The app is signed
locally (ad hoc) on your Mac during installation.

What is in this folder
  app/            the source code (README.md, CHANGELOG-v1.6.md, tests)
  app.asar        the app, ready for the Electron runtime of version 1.5
  app.asar.sha256 the integrity hash of app.asar

If Chord Lab Studio is not installed, the installer downloads the official
Electron runtime from GitHub (about 110 MB) and checks its SHA256. Without
internet it uses npm (Node.js) or opens the app in a Google Chrome window.
The installer and the app follow your Mac's language: Greek or English.
In the app you can change it in Settings → Language.
